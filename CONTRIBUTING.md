# Contributing to Blob

Thanks for your interest. Blob is at a very early stage: the repository currently contains the plan and documentation, and the first code has not landed yet.

## Before you start

1. Read [docs/STATUS.md](docs/STATUS.md) for what exists and the next task.
2. Read [docs/ROADMAP.md](docs/ROADMAP.md) to see which features are intentionally deferred.
3. For anything beyond a small fix, open an issue first so the approach can be agreed.

## Setup

There is no build yet. Once the extension is scaffolded, this section will list prerequisites, install and build commands, and how to load the unpacked extension in Chrome. You will not need any accounts or API keys to run the first milestone.

## Workflow

1. Fork the repository and create a branch from `main`.
2. Keep changes small and focused on one thing.
3. Run the project's checks (to be listed here once they exist) before opening a pull request.
4. Describe what you changed, why, and what you actually verified.

## Ground rules

- Follow the privacy rules in [docs/PRIVACY.md](docs/PRIVACY.md). Changes that collect more data or request broader permissions need discussion first.
- Do not commit secrets, build output, browser profiles, or personal test data.
- Only contribute code and assets you have the right to share under the [MIT licence](LICENSE).
